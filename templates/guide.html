Ereignisse und Sicherheitslogs automatisch weiterleiten.

  1. Öffne deine FRITZ!Box Benutzeroberfläche (http://fritz.box).
  2. Navigiere im Menü zu: System → Ereignisse → Push Service.
  3. Wähle den Reiter Syslog oder die Protokollweiterleitung.
  4. Trage folgende Werte ein:
Syslog-Server IP: 192.168.1.191
Port: 5514
Protokoll: UDP

Linux Server (rsyslog)

Debian, Ubuntu, Proxmox VE/PBS und Raspberry Pi OS.

Mehrere Proxmox-Gäste auf einmal anbinden →

Dieser Befehl installiert rsyslog, richtet die Weiterleitung ein und startet den Dienst. Er funktioniert als root oder mit sudo auf Debian-basierten Systemen.

RSYSLOG_SUDO=; [ "$(id -u)" -eq 0 ] || RSYSLOG_SUDO=sudo; $RSYSLOG_SUDO apt-get update && $RSYSLOG_SUDO apt-get install -y rsyslog && printf '%s\n' '*.* @192.168.1.191:5514' | $RSYSLOG_SUDO tee /etc/rsyslog.d/99-remote.conf && $RSYSLOG_SUDO rsyslogd -N1 && $RSYSLOG_SUDO systemctl enable rsyslog && $RSYSLOG_SUDO systemctl restart rsyslog

Ressourcenüberwachung: Das mitgelieferte scripts/resource-monitor.py prüft CPU, RAM und Dateisysteme und sendet Warnungen über diese Weiterleitung. Installation mit systemd-Timer siehe README, Abschnitt „Ressourcen überwachen“. Auf jedem Host bzw. Gast separat einrichten.
💡 Hinweis: Ein einzelnes @ sendet via UDP. Wenn du TCP bevorzugst, nutze @@.

Synology DSM & QNAP NAS

System-, Speicher- und Login-Logs zentral sammeln.

  1. Öffne das Protokoll-Center in Synology DSM (oder QuLog Center bei QNAP).
  2. Gehe auf Protokollsendung und aktiviere die Option.
  3. Gib folgende Serverdaten ein:
Server: 192.168.1.191
Port: 5514
Übertragungsprotokoll: UDP
Format: IETF (RFC 5424)

Docker Daemon & Compose

Container-Ausgaben direkt an RSyslog weiterleiten.

Füge dies in deine docker-compose.yml bei einem Service ein:

logging:
  driver: syslog
  options:
    syslog-address: "udp://192.168.1.191:5514"
    tag: "mein-service"

pfSense, OPNsense & UniFi

Netzwerk-Firewalls, Router und Managed Switches.

pfSense / OPNsense:

Menü: Status → System Logs → Settings → Remote Logging. Haken bei Send log messages to remote syslog server aktivieren.

Remote Log Servers: 192.168.1.191:5514

Ubiquiti UniFi:

UniFi Network: Settings → System → Advanced → Syslog aktivieren.

HTTP Webhook (REST API)

JSON-Logs direkt per POST-Request senden.

Mit curl von jedem Rechner oder Skript aus:

curl -X POST http://192.168.1.191:8000/api/logs \
  -H "Content-Type: application/json" \
  -d '{"host": "app-server", "app": "checkout", "level": "ERROR", "message": "Datenbank Timeout aufgetreten"}'
